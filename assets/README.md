# Assets

Custom, hand-crafted SVG assets used by the profile README.

- `header.svg` — animated hero banner
- `sec-about.svg`, `sec-stack.svg`, `sec-stats.svg`, `sec-connect.svg` — numbered section headers
- `about.svg` — About Me card with highlighted tech keywords
- `tech-stack-grid.svg` — tech stack as a branded icon grid (fade-in + per-icon glow)

See [`PALETTE.md`](PALETTE.md) for the color tokens, and use
[`preview.ps1`](preview.ps1) to render any SVG to a PNG locally.
