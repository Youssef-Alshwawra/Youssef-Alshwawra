# Brand Palette

The color tokens used across the profile's custom SVG assets.

| Token        | Hex       | Usage                          |
|--------------|-----------|--------------------------------|
| Background   | `#0D1117` | Page / card background         |
| Surface      | `#161B22` | Title bars, chips, gutters     |
| Border       | `#30363D` | Card borders, dividers         |
| Accent       | `#58A6FF` | Headings, links, highlights    |
| Text         | `#C9D1D9` | Primary text                   |
| Muted        | `#8B949E` | Secondary / comment text       |

Accent tints used in the tech-stack icon grid follow each tool's
official brand color (see `tech-stack-grid.svg`).
